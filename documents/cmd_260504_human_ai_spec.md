# 人間AI 実装定義書 (最終確定版：2D投影・滑らか移動・詳細セリフ制御)

## 1. オブジェクト基本構造・描画最適化
- **座標系・移動制御**: 
    - ピクセル単位のワールド座標 (x, y) で管理。
    - **移動は `lerp` や `velocity` を用いて制御し、記号アニメーションを滑らかに実行すること。**
- **スプライト・キャッシュ戦略**:
    - **人間**: 「白丸に黒縁」の `●` をオフスクリーン・キャンバスで1枚生成し、全個体で使い回す。背景色に左右されない高い視認性を確保する。詳細は後述。
    - **ブロック**: 各種（通常、爆弾、火等）の外見を初回にスプライト化し、描画負荷を最小化する。
- **2次元投影の原則**: 人間は「厚みゼロ」の存在。ブロックの前面（手前）を移動・登攀するため、物理的な「埋まり（スタック）」は発生しないものとして扱う。
- **描画メソッド**: 全ての描画は `canvas.drawImage()` を基本とし、実行ループ内でのプリミティブな図形描画命令（arc, rect等）を排除すること。

## 2. 状態別ビジュアル＆アニメーション (キャッシュ画像を使用)
| 状態 | 視覚表現 | アニメーション挙動 |
| :--- | :--- | :--- |
| **歩行** | キャッシュされた `●` | 上下に「ぴょこぴょこ」とはねながら移動。 |
| **登攀** | `●` ＋ `。` (汗) | **画面に背を向け、両手でよじ登る演出。** 左右に揺れ、汗を2〜3個散らす。 |
| **逃走** | `●` ＋ `。` (汗) | 汗を浮かべ、歩行アニメを倍速で実行。 |
| **驚き** | `Σ` (頭上) | 危険察知時、頭上に斜めに `Σ` を表示。 |
| **溺れ/落下**| `ヾ●ﾉ゛`⇔`゛ヽ●ゞ`| パタパタアニメで、空中や水面で手足をバタつかせる表現。 |
| **転倒** | `●` ＋ `u` `,` (飛沫) | **y座標を下げてブロックにめり込ませる。** 周囲に飛沫（u や ,,）を散らす。 |

## 3. システム規則 (スコア・脱落)
- **救出報酬**: 一般人救出 100点 / 重要人物（ドランプ等）救出 500点。
- **脱落判定**: 画面外（下端）に消えた人間は即座に死亡（脱落）として処理。
- **救済条件**: 最低一人が目標高度に到達すればステージ継続。全員死亡でゲームオーバー。
- **クリア条件**: 安全高度がゴールラインに到達すればクリア、の仕様は改修。ゴールラインに到達した後、生き残った人間が全てそこまで登ってきたらクリアとする。安全高度がゴールラインに到達した後、ブロック・爆弾・水位の上昇はストップする。また人間の移動速度は倍速で進行させる。

## 4. AI状態遷移（優先順位順）
1. **溺れ**: 水面下なら最優先。脱出を試みる。
2. **落下**: 足場消失時に移行。落下中は専用アニメとセリフ（`＼ うわあああ ／`）を表示。
3. **登攀**: 前方に段差がある場合。**2段以上の壁も前面に重なりながら1段ずつ繰り返す。**
4. **逃走**: 危険接近時に移行。低確率で「転倒」。壁に阻まれた場合は「うろたえ（シェイク）」へ移行。
5. **獲得**: 付近にアイテムがある場合に移行（演出のみ、拡張用）。
6. **歩行**: 安全状態。左右ランダム移動。定期的に「観察（停止）」を行う。

## 5. 視覚的フィードバック（セリフ吹き出し）
- **表示形式**: キャラクターの頭上に小さく `＼ テキスト ／` を表示。
- **セリフ代表者（ID優先制）**: 
    - 密集地帯（例：3x3ブロック内）で、**内部IDが最も若い個体**のみがセリフを表示する。
    - 重要人物はID先頭に配置し、最優先で発言させる。
- **状況別セリフ辞書**: ステージの言語設定（ランドマーク）に応じて切り替えること。
    - **危機・水位接近**: `＼ 助けて！ ／`, `＼ HELP! ／`
    - **落下中**: `＼ うわあああ ／`
    - **溺れ中**: `＼ ぶくぶく… ／`
    - **着地成功**: `＼ 助かった… ／`, `＼ ふぅ ／`
    - **転倒時**: `＼ 痛っ！ ／`, `＼ しまった！ ／`
    - **観察中**: `＼ ･･･ ／`

## 6. 内部パラメータ（※定数として集約し、後日調整可能にすること）
- **速度係数**: 歩行 1.0 / 登攀 0.5 / 逃走 1.7 / 高速登頂 2.5
- **転倒時間**: 2.0秒（※危険接近時は残り時間に関わらず即時復帰）
- **溺死タイマー**: 5.0秒 / **セリフ表示時間**: 2.0秒
- **高速登頂発動**: 目標高度（平均）から 3ブロック分 以上低い場合に発動

## 7. 実装上の留意点
- **背面演出**: 登攀時は揺れやパーティクル発生位置を工夫し、プレイヤーに背を向けて必死に登っている印象を強化すること。
- **柔軟な設計**: `Human` クラスをベースとし、重要人物等のプロパティ上書きを容易にすること。
- **拡張性**: 背景ランドマーク等の複雑な要素も将来的に1枚のテクスチャとしてラスタライズできる構造を維持すること。

- 開発中のため、以下はテスト数値とする
    - 初期人間数：10人
    - 重要人物人数：1人
    - 危険察知距離：自分がいるブロックエリアの中心点から1ブロック分の前後左右上下。水位判定は自分が居る高度から、-30メートル（3ブロック分）の距離と設定。


# Humanoid Entity Visual Specification (ver 1.1)
## 1. Asset Structure & Memory Management
- **Instancing Strategy**: 100体以上の描画負荷を抑えるため、個体ごとにスプライトを持たず、基本パーツ（Texture Atlas）をGPUメモリに1セットのみキャッシュし、各個体はそれを参照（Draw Instancing）する。
- **Texture Atlas Components**:
    - **A: Body**: 正円 (Perfect Circle) / 衝突判定の基準点。
    - **B: Hand**: 小サイズの正円 (Small Circle) / 胴体上部に左右配置。
    - **C: Foot (Normal)**: 半楕円 (Semi-oval / Flat Bottom) / 接地・歩行用。
    - **D: Foot (Climb)**: 楕円 (Oval) / 登攀時の「足の裏」表現用。

## 2. State-Based Sprite Swapping
個体の内部ステータス（Climb_Flag）に基づき、足パーツの参照先（C または D）を動的に切り替える。

| State | Foot Part | Visual Intent |
| :--- | :--- | :--- |
| **Idle / Walk** | **C: Foot (Normal)** | 接地感、安定した二足歩行の表現。 |
| **Climbing** | **D: Foot (Climb)** | 壁面に対して足裏を向けている必死さの表現。 |

## 3. Procedural Animation Logic
フレームごとのアニメーション画像は不要。以下の座標計算（Offset）で動作を表現する。

- **Walk / Run**: 
    - 胴体(A)の移動に同期し、足パーツ(C)を交互に「（前・上）→（後・下）」へスライド。
- **Climb**: 
    - 足パーツを(D)に切り替え。
    - 左右の足を胴体中心から外側へ弧を描くように交互に動かし、垂直移動を表現。
- **Death / Dispersion**: 
    - 連結（Relative Position）を解除。
    - 各パーツ(A-D)を独立した物理オブジェクトとして飛散させた後、プールへ回収する。

## 4. Technical Constraints
- **Resolution**: ドット絵スタイルを想定。
- **Complexity**: 100人同時表示時でも60fpsを維持するため、1パーツあたりの頂点数または描画負荷を極限まで抑えること。
- **Scale**: 各パーツのサイズ比（Hand < Body, Foot ≒ Body/2）を厳守。
