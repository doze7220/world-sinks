世界沈没 - README

概要
  あなたは神となり、落下するブロックを操作して「大地」を作り、
  水位上昇から世界を救うパズルゲームです。

目的
  横一列が地面で埋まった高さが「安全高度」となります。
  安全高度を GOAL_METERS（デフォルト 200m）まで作り上げるとクリアです。

操作
  ← / → : ブロックを左右に移動
  ↑     : ブロックを回転（ウォールキック対応）
  ↓     : 高速落下（押している間）
  Space : タイトル/イントロ/クリア/ゲームオーバーの進行（押しっぱなし防止のため離す必要あり）

基本ルール
  - ブロックは色ごとに分かれ、同色が4つ以上繋がると消えます（上下左右で接続判定）。
  - 消えた分だけ地形が変化し、安全高度が上下します。
  - 水位は時間経過やイベント（爆弾）で上昇します。水位が安全高度を超えると警告が発生します。
  - 警告は点滅（CAUTION）→猶予カウントダウン（秒表示）→時間切れでゲームオーバーになります。
  - 爆弾は一定条件で落下し、着地後にタイマーで爆発して周囲を破壊します。

表示説明
  - 画面右側のレーダーで現在の水位、ゴール、現在の安全高度、カメラ表示範囲を確認できます。
  - 画面上のライン：水位（青）、安全高度（白）、ゴール（黄）で視認できます。
  - 右上に「水没までの残り時間（秒）」が表示されます。

ゲームオーバー
  - 水位が安全高度を超え、猶予時間が切れるとゲームオーバーになります。
  - ゲームオーバー時は専用演出（テキスト表示・ブロック落下・水位急上昇）が再生されます。

クリア
  - 安全高度が GOAL_METERS に達するとクリア。紙吹雪と祝賀演出が発生します。

開発者向け（簡易）
  - 実装言語: JavaScript（HTML5 Canvas）
  - 主要ファイル: ゲームロジック（main.js 相当）、index.html（Canvas）、アセット（sprites, audio）
  - 主要関数: createInitialGrid(), newPair(), hit(), merge(), flagErase(), startCascade(), updateCascade(dt), update(dt), draw(), drawRadar()

既知の注意点
  - TOTAL_ROWS が大きいため、低スペック環境では描画負荷が高くなる可能性があります。
  - パーティクルや confetti の数はパフォーマンスに影響します。必要に応じて上限を設定してください。
