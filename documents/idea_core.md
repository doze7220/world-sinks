# アイデアメモ

## caution演出
    - 危機
        - 水位が安全高度より高い
        - 火事
        - 爆弾
        - 危険な天候（竜巻・雷雨・吹雪）
    - 世界沈没までのカウントダウン
        - 世界沈没危機になると、天候が豪雨になる
        - cautionから抜ければ豪雨が止む
    - caution演出が表示されている間は、天候が変わらない

## 別の神様と対戦
    - 神パワーで「相手の邪魔」ができるようになる
    - 神パワーで「相手の邪魔を防ぐ」ができるようになる
    - 相手の人間を奪える
        - 信者を増やす
        - 早くゴールよりも「生き残った自分の信者が多いほうが勝ち」
        - 同じ画面でやったほうが面白いかも…？（要検討）
            - 協力プレイで横幅２倍、安全高度を作る労力も２倍

## 天候を表現する
    - 世界各国のステージで、発生しやすい天候がある
    - 晴れ・曇り
        - ゲーム的な要素はなし
    - 強風
        - ランダムで砂ブロックが壊れる
        - 水面が大きく波打つ
    - 竜巻
        - 人間を吹き飛ばす
        - ランダムで最上段に積まれているブロックを吹き飛ばす
    - 雨
        - ブロックが消えるまでの時間が短くなる
        - 爆弾の火が消え、無力化する
        - 火事が収まる
        - 水位の上昇が早くなる
    - 雷雨
        - 草原ブロックに落雷すると一定時間火事になる
            - 人間が死ぬ/消化までブロックを移動できなくなる
        - 落雷が人間に直撃すると死ぬ
        - 落雷が爆弾に直撃すると即座に爆発する
        - 水位の上昇が早くなる
    - 吹雪
        - 雪が積もり勝手にブロックとなる
            - 雪はあらゆるブロックの上に積もる
                - 常にその列の最上段に積もる
                - 積り切る前にブロックを積めば雪は消える
                - 一定時間積もると、雪ブロックとなる
        - 雪ブロックは4つ以上繋がっても崩壊しない
        - 雪ブロックは他のブロックの崩壊に巻き込まれて消える
        - その後に雨・雷雨・豪雨・猛暑になると溶けて消える
        - 洪水が凍る、この天候の間は水位が上昇しない
    - 猛暑
        - ブロックの消去時間が遅くなる
        - 雪ブロックを溶かす
        - 泥沼を粘土に戻す
        - 人間の移動速度が遅くなる、人間が汗をかく演出を出す
        - 水位の上昇が遅くなる
        
## ブロックの種類と特性
    - デフォルト難易度では「草原」「岩肌」「砂漠」「粘土」の4種類
    - 難易度が上がると「氷原」「泥沼」が一部ブロックと入れ替わる
    - 難易度最高難易度だと「雪原」が一部ブロックと入れ替わる

    - 草原ブロック
        - 落雷すると火事になる
        - 猛暑で枯れて砂漠ブロックになる(要検討・慎重に)
            - 砂漠ブロックになった結果、強風で壊れる、連鎖が発生するなど
        - 泥沼化しない
        - たまに花が咲いており、人間が感想を漏らす
    - 岩肌ブロック
        - 爆弾の爆発でも消えない
        - 登る時間が早い
        - 下が砂漠・雪ブロックだと、押しつぶしてしまう
    - 氷原ブロック
        - 摩擦が少ないので滑る、このブロックの上で止まることができない
            - このブロックに積まれたブロックに対して登ることができない
        - 登ることが出来ない
    - 雪ブロック
        - 吹雪で積もる、自動生成でこのブロックが振ってくることはない
            - 詳しくは「##天候」にて
        - 人間の登る時間がかかる
        - 人間の移動速度が遅くなる
        - 雨・雷雨・豪雨・猛暑で溶ける
    - 砂漠ブロック
        - 強風によってランダムに壊れる
        - 人間の登る時間がかかる
    - 粘土ブロック
        - 雨などで泥沼化する
            - 泥沼化すると人間の移動速度が遅くなる

## アイテム
    - 時々ブロックの中に、アイテムが隠されている
    - アイテムは人間が取得すると、その効果がステージクリアまで永続で持続する
        - 誰か1人が取得すれば、全員にその効果が発揮される
    - また、アイテムは複数所持でき、効果が重複する
    - アイテムは爆弾と同じように、一定時間で消える

### アイテムの効果
    - 基本的には気候・地形デメリットを防ぐ効果

    - ロープ：登る速度が上がる、複数個取得で速度UP
    - スニーカー：移動速度が上がる、複数個取得で速度UP
    - 救命胴衣:一定時間水に浮いていられる、水に溺れる時間が伸びる
    - 盾:爆弾の爆発に巻き込まれても死ななくなる、何度か食らうと壊れる
    - 消化器：人間が火を消せるようになる、複数回使うと消費
    - 長靴：泥沼の移動速度低下が緩和される
    - パラシュート：ある程度の高さから落下しても死ななくなる、強風時には使えない
    - 水筒：猛暑でも移動速度が低下しない
    - ゴムガッパ：雷にあたっても死なない
    - スパイクシューズ：雪ブロックの速度低下緩和、氷原ブロックですべらなくなる

## 神パワー
    - 生成したブロックを消すことで、神パワーが溜まる
    - 神パワーが一定以上溜まると、神パワーを使える
    - 神パワーが溜まると選択肢が3つ(あるいは4つ)表示されて、一つを選ぶ
        - 選択はカーソルキーの←↑→
        - カーソルキーを押した瞬間に実行される
    - 使うと神パワーが消費され、0に戻る

### 神パワーの使い道
    - 火事を消す
    - 人間を数ブロック上に移動させる
    - 風を起こす
        - 天候はそのままで、風のエフェクトだけ発生させる
        - 砂漠ブロックを吹き飛ばす
        - 雪ブロックを吹き飛ばす
    - 雷を落とす
        - 天候はそのままで、雷のエフェクトだけ発生させる
        - 砂漠ブロックを破壊する
        - 岩肌ブロックを破壊する
        - 草原ブロックを火事にする
        - デメリットしかないからこのパワーは没かな
    - 天候を晴れにする
        - エフェクトなし、今おきている天候のキャンセルの位置づけ
    - 死んだ人間を蘇らせる
        - 死んだ人間がいるときだけ選択肢出現
        - 蘇った人間は安全高度地点に出現
        - 死んだ人間の中から一人ランダムで選んで蘇らせる
        - 死んだ人間を全員蘇らせる
    - 水位を下げる
    - 安全高度以下のブロックを全て岩ブロックに変換する
    - 爆弾を一定時間出現させないようにする
    - 爆弾を全て無力化する
        - 爆弾がマップ上に存在する場合のみ選択肢出現

        - 登れないブロックがある
        - 必ず1ブロックずつ登る
    - 安全高度と離れすぎた場合は、高速移動・高速登頂となる
        - 安全高度から2ブロック以上下にいる場合
    - 人間は頭頂部が水位以下になると溺れる

## 人間の登攀ルート分岐
    - 人間を登場させる場合、今のゲームデザインだと安全高度以下は全て壁、つまりうろちょろする必要がなく、ひたすらに安全高度まで垂直に登っていくだけとなる
    - 解決作としては「登れないブロック」か「ブロックが存在しない空間」を登場させる必要がある。だがブロック個性を入れたところで解決しない可能性が高い。ルートを分岐させるだけの登れないブロックを登場させると、かなりの数が必要になる。その数の該当ブロックを出すと、ゲームにならないのではないか。
    - 別解決策として以下のブロックを検討
### 横幅２～３のブロック
    - 通常のブロックと同じ挙動をするが、サイズが横に２～３倍（回転させれば縦に２～３倍）
    - １箇所が支えられている場合は、それ以上落下しない
    - ブロックサイズは大きいが連鎖の際にはあくまで１ブロックとして計上する。
    - 上手く使えば効率よく安全高度を作れる。が、下手に積むと下に空白を産む。
    - 出現頻度は他ブロックの1/5程度（出現確率はパラメータ化し、あとで微調整）。
### 空気ブロック
    - 半透明の白い板、ほぼ透明に近いがブロックとして認識できる程度
    - 通常のブロックと同じ扱いだが、単純に登れない
    - 登場頻度は他ブロックと同程度
### 磁石ブロック
    - (便宜上)右上の角にN、左下の角にSを斜めに記載。右上対角線を赤、反対を青で塗り分け。回転させても絵柄の方向は変わらない。
    - 横にくっつくブロック。落下中に側面が何かのブロックと接触したら、そこで落下が止まる。
    - くっつく際に磁力エフェクトを表示し、ガチャンとくっつく表現を行う
    - このブロックの上には普通に他ブロックを積み重ねて行くことができるが、それ以上落ちない
    - 後から落としたブロックは、下に空白があっても側面が磁石ブロックと接触したら、そこで固定化される。
    - 磁石ブロックの左右に他ブロックがある場合は、下に空白が出来ても落下しない。左右のブロックが破損すれば落下。あるいは左右のブロックが落下する場合は、それに合わせて落下する。左右がくっついている場合、そのブロックは１塊として扱われる。
    - 出現頻度は他ブロックに比べて1/3程度にする（パラメータ・ステージ設定・難易度によって出現頻度は変化）
    - 磁石ブロック同士は反発しあう。横方向にくっつけると、後からくっつけようとしたほうが反動で１マスずれる。（その先にあるブロックを壊して代わりに居座る）縦方向にくっつけようとすると、強制的に１マスの隙間ができて、隙間を作る。ゆえに絶対に連鎖崩壊はしない。
    - 爆弾で破壊はされる。その場合、上に乗っているものは全て落ちる。
    - 面白そうだがルールが面倒くせえな。細長いブロックのほうがマシか。


# 人間AI
## 座標管理
- ブロック単位での移動ではない、グリッドなしのワールド座標、ピクセル単位で移動する。
- 自分の上下左右2ブロックを監視する

## 横移動
- 安全であればランダムな方向の横に向かって歩く。
    - ブロックの端まで移動したらその場で立ち止まり、観察。
    - 自分の周囲1ブロックに危機となる状況がない場合を「安全」と定義
    - 危機となる状況は「水位が間近に迫っている、爆弾、足場の崩壊」
        - 水位だけは自分から50メートル(5ブロック分)近づくと危機と判断する
    - 後々実装予定の「危険な天候、火事」なども含める想定
- 危険な状況を察知した場合
    - まず驚く
    - 次に危険から逃げようと逃走モードになる
- 通りがかったところに「上に登れるブロック」があれば、それについて登ろうとする。
    - 実装予定の「ブロックの特性」によって、登れないブロックを定義する想定
- アイテムを見つけた場合は拾い、アイテムを頭上に掲げて喜ぶ
    - アイテムについては未実装、今後実装予定
- 安全かつ登るブロックがない場合は、時々立ち止まる

## 上移動（登攀）
- 上に登れそうなブロック（登攀不可のブロック以外）を、手足を使ってよじ登る
    - 昇る位置はブロック中央から80%分のエリアのみ、登る位置はエリア端ギリギリではなく、位置を多少ランダムとさせる。
    - 登ってる最中、上に爆弾が落ちてきても気が付かない。登った後に驚き逃走。
    - よじ登っている最中にブロックが崩壊した場合は、落下する。
    - よじ登っている最中は回避行動を取らない。
    - 登攀は問題がなければ1ブロック分完了するまで継続する。
- 1ブロックよじ登った時点で、周囲を確認し、一時横移動モードに映る。
    - 周囲に危険がなく、かつその場にまだブロックがあれば、また登攀し始める。

## 逃走モード
- 危機を察知したときは逃走モードとなり、動きが早くなる
    - 危機の逆方向へと走り出す
    - 横移動は走りとなる
    - 登攀は急ぐ
    - アイテムを無視するようになる
- 低確率で転び、余計に時間を食う
- 低確率で登るのに失敗し、落下する
- 危険から3ブロック離れれば一時立ち止まり、周囲を再確認する
    - 逃走先でまた危険があった場合は、また即座に驚き→逃走となる
    - 崖・エリア端・危機に挟まる、などで3ブロック以上離れられないときは、その場でオロオロとうろたえる。
- 危険が水位の場合は、水位から50m以上はなれれば立ち止まり、周囲を再確認する

## 行動優先順位
- 以下の行動優先順位
    - 登攀 : 登攀中は他の行動を取らない、逃走中に登れる箇所があれば最優先で登り始める。
    - 逃走 : まず危険エリアから離れることを優先とする
    - 逃走(水位) : 走り回って登れる箇所を探し、急いで登ろうとする
    - アイテム取得 : アイテムを見つけたら獲得する
    - 歩き : ある程度の距離をランダムで移動する、1ブロック境界をまたぐ場合に観察を行う。想定した距離を移動した後、一時立ち止まって休憩。
    - 観察 : 周囲をチェック、登れる位置、アイテム、危険を探す。逃走時は走りながらチェック。
    - 休憩 : 一定時間立ち止まって休憩。
