# 企画書

### タイトル
**世界沈没**

### コンセプト
プレイヤーは「神」となり、落下するブロックを操作して「大地」を作り上げ、水位上昇による世界沈没を防ぐパズルアクションゲーム。短時間での判断と積み上げの戦略性を楽しむ。

### コア体験
- **緊迫感**：時間経過で上昇する水位に追われるプレイ。  
- **戦略性**：ランダムなブロック形状（サイズ2〜4）と回転・移動で最適配置を模索。  
- **達成感**：安全高度をゴール（デフォルト200m）まで作り上げる達成感。  
- **演出**：波・雲・パーティクル・紙吹雪・爆弾などの視覚演出で没入感を強化。

### ターゲット
カジュアル〜コアなパズルゲーム層。ブラウザで短時間プレイを想定。将来的にモバイル（タッチ）移植を想定。

### プラットフォーム
HTML5 Canvas + JavaScript（現状）。将来的にモバイル（タッチ）移植を推奨。

### 主要ゲームループ（要約）
1. ペアブロックが上から落下。  
2. プレイヤーが左右移動・回転・高速落下で配置。  
3. 同色ブロックが4つ以上繋がると**クラッキング→消去**。  
4. 消去で地形が変化し、安全高度が上下。  
5. 水位が安全高度を超えると**警告→猶予（点滅→カウントダウン）→ゲームオーバー**。  
6. 一定条件で**爆弾**が落下し地形を破壊、局面を変化させる。  
7. 安全高度がゴールに達すると**クリア（紙吹雪）**。

### 差別化ポイント
- **安全高度（横一列が埋まった高さ）**をゲーム進行の中心に据えた独自ルール。  
- **水位（メートル換算）＋レーダー表示**で全体状況を把握できるUI。  
- **爆弾やランダム落下物**でダイナミックな地形変化を導入。

### マネタイズ案（任意）
- 無料プレイ＋広告（短いリワード広告で続行権）  
- スキン/テーマ（背景・ブロック色）有料販売  
- ランキングやシーズンイベントで課金要素（任意）

### 開発ロードマップ（短期→中期）
- **短期（MVP）**：ブラウザ版完成（現在のロジックを安定化、チュートリアル追加）  
- **中期**：難易度調整、スコアリング、リプレイ保存、モバイル対応（タッチ）  
- **長期**：ランキング、イベント、追加ギミック（新ブロック、天候、ボス）  

### 必要リソース（目安）
- 開発：1〜2名（JS/Canvas） 2〜3ヶ月（MVP）  
- アート：スプライト・UI・背景（軽量）  
- サウンド：BGM 1曲、SE（落下・消去・爆発・UI）  
- テスト：クロスブラウザ、モバイル実機

### KPI（例）
- 1セッション平均プレイ時間：5分以上  
- 1日アクティブユーザー（DAU）目標（ローンチ初月）: 1,000  
- リテンション（Day1/Day7）: 30% / 10%（目標）
